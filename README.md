# bga-brass-userstyle
Userstyle for Brass on BGA.

## Features
Configurable aspects of industry tiles on the board:
- Zoom for tile level and VP icons
- VP icons font
- Coal/iron cube size

## Prerequisites
<a href="https://github.com/openstyles/stylus#readme">Stylus</a> or some other way to apply a .user.styl or css to websites.

## Notes
Tested with Lancashire. It should work fine with Birmingham as well.
It’s of no use for Pittsburgh (as of 09/2026) due to implementation differences.
