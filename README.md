# bga-brass-userstyle
Userstyle for Brass on BGA to tweak the UI to your needs.

## Features

### Main board
- Background brightness
- Plain background
- Hide border image ("lacework")

### Player mat overview
- Zoom (1% to almost hide it completely)
- Position
- Tile level zoom
- Count dots’ size

### Locations / Industry tiles
- Zoom for tile level and VP icons
- VP icons’ font details
- Coal/iron cubes’ size
- Flipped tiles’ brightness
- Used location cards’ size

## Prerequisites
<a href="https://github.com/openstyles/stylus#readme">Stylus</a> or some other way to apply a .user.styl or css to websites.

## Install & Usage
Open [bga-brass.user.styl](https://github.com/yzemaze/bga-brass-userstyle/raw/main/bga-brass.user.styl) and hit Stylus’ install button.
Open the config dialog within Stylus and change the settings to your preferences.

## Notes
Tested with Lancashire. It should work fine with Birmingham as well.
It’s of less or even no use for Pittsburgh (as of 09/2026) due to implementation differences.

If you’d like to see specific tweaks [suggest them](https://github.com/yzemaze/bga-brass-userstyle/issues).
